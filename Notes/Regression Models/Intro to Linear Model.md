
## Equation for Linear models

$$  
\hat{y} = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b  
$$  
  
### Where  
  
| Symbol                  | Meaning                                         |     |
| ----------------------- | ----------------------------------------------- | --- |
| $\hat{y}$               | Predicted output (prediction made by the model) | y   |
| $x_1, x_2, \ldots, x_n$ | Input features                                  | x   |
| $w_1, w_2, \ldots, w_n$ | Weights (importance of each feature)            | m   |
| $b$                     | Bias (intercept or starting value)              | c   |
  

## Dimensions used for prediction

| Number of features | Number of dimensions |
| ------------------ | -------------------- |
| 1                  | line(2d)             |
| 2                  | hyperplane(3d)       |
| 3                  | and so on            |
| 4                  | and so on            |


Best used when there are more features than training data points
