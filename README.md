# ML Notes

A collection of my personal notes while learning machine learning — covering
model-specific concepts, math foundations, and AI-assisted study material.

## 📁 Structure

```
├── notes/            # Markdown notes on individual ML models/topics
├── handwritten/       # Scanned handwritten notes — deep math derivations
├── ai-generated/      # AI-assisted material (see note below)
└── README.md
```

## 📒 notes/
Markdown notes on individual ML models and concepts (originally drafted in
OneNote), covering intuition, key formulas, and use cases.

## ✍️ handwritten/
Scanned handwritten notes focused on the underlying mathematics — derivations,
proofs, and worked examples that are easier to write by hand than type.

## 🤖 ai-generated/
Contains material generated with Claude (Anthropic) used as a study aid —
summaries, alternate explanations, or practice material. This content is
clearly separated from my own notes for transparency. See
[`ai-generated/README.md`](./ai-generated/README.md) for details on what's in
there.
